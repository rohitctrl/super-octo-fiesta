CrocBridge needs croc

CrocBridge moves files with croc, a small command-line tool. Install it once, then come back here.

Your installed croc is too old to receive the transfer secret safely. Update it with the same commands below.
macOS
brew install croc
Linux
curl https://getcroc.schollz.com | bash
Windows
winget install schollz.croc
